# 自适应 q 分箱后的 B1 实测峰顶

2026-10-24。按用户指定策略：小 q 直接提取，高 q 合并 3 或 5 个原始 q 通道再提取。

**590 和 n0 均得到明显上升、随后趋于宽平台的 B1 观测色散。** 在正 q 从
0.001 到 0.015 Å⁻¹ 的范围，5 通道方案的峰顶分别上升 1.016 和 1.021 eV。
负 q 和 3 通道方案保留同样的总体趋势。20w 也有上升的包络，但高 q 峰顶
对重采样和前后帧分组明显更敏感。

这延续了论文关于 B1 为强阻尼、上升 plasmon-like candidate 的观察；采用
2026-05-14 修正后的 q 标定。本轮的实际证据是原始序列重新处理的计数谱，
不是从旧论文曲线读取的数据。相邻 NJUThesis 克隆只用于研究背景，未将其
旧版源文件当作最终提交证据。

## 数据与提取

1. 读取 590、n0、20w 三组原始 300 帧序列，复用已验证的逐帧能量对齐、
   q 漂移与能量零点。三份原始文件 SHA-256 再次核对不变。
2. |q| ≤ 0.006 Å⁻¹：一个原始 q 通道宽；更高 q：分别以 3、5 通道组成
   连续、不重叠的积分区间。正负 q 分开，q=0 不提取。最外侧不够完整分箱
   的通道不使用，禁止为了凑宽度重复边缘通道。
3. 10w 的 dq=0.0005 Å⁻¹，因此高 q 宽度为 0.0015/0.0025 Å⁻¹；20w 的
   dq=0.00025 Å⁻¹，对应宽度为 0.00075/0.00125 Å⁻¹。漂移校正通过像素
   区间重叠权重完成，边界像素可贡献分数计数。图上横线是积分宽度，不是 q 误差。
4. 保持上一轮 16 meV 能量分箱的**宽度与边界**。最终准备范围为 200–2200 meV。
   热图直接显示这些计数，只对每列除以其 300–1800 meV 范围最大值。
   没有拟合背景扣除、除运动学因子或解卷积。
5. 在 300–1800 meV 内，以 100 meV FWHM 的高斯平滑辅助寻峰；保留 prominence
   大于该窗最大计数 2%、间距至少约 64 meV 的局部峰。最高局部峰用相邻三点
   抛物线插值得到峰顶。若最大值落在能窗边缘，则不赋主峰。所有其他局部峰
   单独写入 candidates.csv；没有把小波动命名为额外振子。
6. 每个 q 独立处理，不使用相邻 q 热启动、递增约束、预设色散曲线或两个振子。
   `peak_meV` 的定义是**实际计数宽峰的峰顶**，与振子 E₀ 和内禀损失峰顶分开。

## 数值结果

以下为正 q，低 q 单通道、高 q 5 通道方案，单位 eV。

| q (Å⁻¹) | 590 峰顶 | n0 峰顶 |
|---|---:|---:|
| 0.0010 | 0.459 | 0.439 |
| 0.0025 | 0.712 | 0.678 |
| 0.0050 | 1.160 | 1.206 |
| 0.0100 | 1.430 | 1.422 |
| 0.0150 | 1.475 | 1.460 |

从 0.001 到 0.015 Å⁻¹，590 正 q 上升 1.016 eV，条件帧重采样 95% 区间
[0.917, 1.046] eV；n0 上升 1.021 eV，区间 [0.859, 1.124] eV。
同范围负 q 分别上升 1.027 和 1.024 eV。n0 末点仍触发宽置信区间及前后帧
差异标记，因此这些升幅描述总体能区移动，不代表平台每个点都精确确定。

即使限制在上一轮相同的正 q 区间 0.0025–0.015 Å⁻¹，590 和 n0 的总谱
峰顶也分别上升 **0.764 和 0.782 eV**。之前 n0 的 283 meV 是双分量全局
模型中低能振子 E₀ 的变化；两者度量的对象不同。

高 q 两种分箱均保留约 1.3–1.5 eV 的宽平台。5 通道图面更平顺，部分点的
区间缩短；它不能保证所有峰顶都稳定。分箱方案的中心位置不同，3/5 曲线
不是每一点都能直接相减，也不把同一批数据的两个处理版本当成独立重复实验。

20w 在 |q| 约 0.001 时的峰顶为 0.46–0.51 eV，较高 q 的主包络进入约
1.3–1.6 eV。5 通道方案在 +0.0155 的升幅为 1.017 eV，但 95% 区间
[0.666, 1.206] eV，且有时间分组差异；负 q 也很宽。优先用两组 10w
约束主曲线，20w 高 q 暂作对照。三个数据集的物理接收宽度不同。

## 重复性与标记

- 300 次循环移动块 bootstrap，每块 10 帧；每次重采样在所有 q 上使用相同
  帧权重，保留跨 q 波动。区间来自重采样谱重新寻峰，允许不同局部峰成为主峰。
  没有固定在原峰附近搜索来人为缩小区间。
- 比较前 250 与后 50 帧的独立峰位，以及 64/144 meV 两种平滑 FWHM。
- “较稳定”要求：原谱存在内点峰，重采样检出率 ≥90%，95% 区间宽度
  ≤200 meV，前后帧峰位差 ≤150 meV，平滑敏感性 ≤100 meV。阈值是本轮
  经验复核规则，不是统计显著性定义。
- 不满足规则的点以空心/叉号保留；q=0 与未检出内点峰不赋主峰。
- 这些区间以已测 300 帧、固定校准、固定漂移估计和提峰规则为条件；未计入
  背景、动量接收积分或模式身份的不确定性。

两组 10w 在约 |q|=0.004–0.006 Å⁻¹ 的宽谱顶部发生较快移动，部分点的
bootstrap 区间也变宽。这个区间值得下一轮专门比较“单个模连续色散”和
“宽成分相对权重交换”。当前最高峰追踪不能替代这一模式身份检验。

## 判断与下一步

**本轮支持把 B1 表述为有显著上升观测色散的 plasmon-like 宽谱分支。**
它提供了一个独立于双振子分解的实验约束。推荐小 q 单通道、高 q 5 通道
作为展示方案，同时保留 3 通道敏感性对照及所有复核标记。

下一轮应以原始单谱和这些峰位为约束，对小 q 的上升段做含实际接收积分、
能量卷积与运动学权重的前向模型比较，并专门检验 0.004–0.006 Å⁻¹ 的
谱形重排。模型应解释计数峰顶为何上升，以及是否由同一个低能模主导；
高 q 平台中的低能/高能成分身份仍由这个比较决定。

- `peaks.csv`：312 行，包含六种数据集/分箱组合中的全部 q 点及失败标记；
  `candidates.csv`、`rise.csv` 保留候选和端点差。

  与 bootstrap 结果在两方案间完全相同。

  上一轮同中心、同宽度的 q 单谱，125 个公共能量通道逐帧完全一致。
