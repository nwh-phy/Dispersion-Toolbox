# 590 / n0 / 20w：真实数据图片

本组图片直接使用三组真实 NPY 采集（每组 300 帧），以及已经完成的 v3 训练拟合。它替代前一轮理论示意图作为“看我的真实数据”的交付。本轮没有重新选峰、重新拟合，也没有用合成谱替换实验像素。

## 图 1：真实 q–E 图

沿用已经核验的能量和 q 漂移轨迹，从只读原始帧重新提取正 q 范围 0.0025–0.015 Å⁻¹。

- 590、n0：q 步长为探测器的 0.0005 Å⁻¹，积分宽度 0.0015 Å⁻¹；
- 20w：q 步长为探测器的 0.00025 Å⁻¹，积分宽度 0.00125 Å⁻¹；
- 四个能量通道求和为 16 meV，累加全部 300 帧；
- 每个 q 在显示的 0.5–1.8 eV 窗内归一化，以比较谱形；不据此比较绝对振子强度；
- 不扣背景、不平滑能量、不插值生成额外 q 点；相邻 q 窗有重叠，统计上相关；
- 这里的“真实数据”已经校准、漂移校正和分箱，不能称为未经处理的探测器原图。

每个已有正 q 拟合位置的重新提取结果，都与冻结的 composition/*.npz 逐能量比对；原始文件、前序校准和拟合签名在绘图前核验 SHA-256。

## 图 2：真实留出谱上的分量

黑点是最后 50 帧实际计数，误差棒沿用逐帧噪声估计。蓝线是前 250 帧拟合的总谱乘束流比例；红绿线是已经经过运动学、完整 Q 接收积分和 Gaussian 能量分辨率后的两个 B1 计数贡献；灰点线包含邻近能带和背景。

图中只展示 0.5–1.8 eV，拟合本身仍使用之前的 0.5–3.4 eV 窗。红绿线是条件分解，不能当作独立测得的两条 plasmon。最后 50 帧没有参加参数拟合，但此前模型设计看过留出表现，因此不是盲法验证。

## 图 3：观测谱顶与模型裸峰顶

黑点来自全部 300 帧谱的 B1 窗极大值；仅在取峰时做 σ=32 meV 的 Gaussian 平滑。蓝方块是已有总谱预测的极大值。红绿线是拟合模型在去掉测量权重后，其两个裸损失分量的解析峰顶。

必须保留的模型约束：main_double 中一支允许屏蔽色散及 q 依赖宽度；另一支 E0 和宽度被设为常数。彩色虚线表示这个固定分量，不能把其水平性当成从数据独立发现的结果。n0、20w 的屏蔽参数触及上界，图上直接标注。峰顶也不同于模型 E0、复极点或已被确认的材料本征频率。

因此，真实数据支持的图示结论是：存在可重复的宽谱形复杂性，双贡献模型可以解释其中一部分；上升的观测谱脊与两种较弱色散贡献相容。它尚不能证明“一个 plasmon 被运动学因子分裂成两个不色散 plasmon”。

没有执行原始谱直接除以 K 的操作。有限接受范围测量的是 R * ∫W K L d²Q，一般不能通过除以标称 q 的 K 唯一恢复 L。图 3 的材料谱形来自含测量算子的模型推断，而非独立解卷积。
