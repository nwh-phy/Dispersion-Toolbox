# 2026-10-23 q-EELS 无人值守探索结果

**最值得进入下一轮 GUI 优化的是“原始帧能量 + q 双轴漂移校正”，并为拟合参数增加可识别性诊断。** 这轮处理把 n0 的零损峰宽度从 68.5 meV 恢复到 21.1 meV；又通过弹性束心测得的亚像素 q 漂移，消除了 590 在正负 q 两侧约 10% 的时间强度偏移。后者直接改善了未参与拟合的时间段预测。

本轮已经完成实际计算：900 帧、360 次预设拟合、80 次合成拟合、2304 次帧/块重采样，以及发现时间异常后追加的 18 次 q 漂移对照。独立分支 `codex/qeels-processing-exploration` 从研究提交 `3d66386` 建立。原始数据、GUI 和原研究分支均保留。

## 1. 数据处理的实测改善

| 数据 | 使用帧数 | 元数据坐标中的最终零损原点 / meV | 能量漂移跨度 / meV | 求和后 ZLP FWHM / meV | 逐帧对齐后 / meV |

| n0 | 300/300 | −196 | 64 | 68.50 | 21.12 |

JSON 的能量零点不是这些原始序列的实测零损峰位置。首次检查若直接在元数据 ±100 meV 内找峰，会错误保留 56/47/6 帧；该尝试已中止，记录保存在本地 `preliminary_wrong_energy_origin/`。最终流程先校准共同弹性原点，再对齐每帧，三组均保留全部 300 帧。Python 和既有 MATLAB 对齐结果逐项一致，保留支撑区计数差为零。三组均检出第 461 列的哨兵坏通道，已明确掩蔽。

分箱后信号窗的实测方差/均值 g 约为 0.962–1.060；简单套用元数据 0.82 会低估这里的计数噪声。采用实测噪声与采用 0.82 泊松权重时，q=+0.005 Å⁻¹ 的低能 E₀ 改变约 1 meV，但残差量级的判断不同。因此噪声应是可核验的数据属性。

## 2. 新发现：q 漂移解释了低 q 的时间强度偏差

前 250 帧与后 50 帧的弹性束心差：590 为 **0.428 q 像素**，n0 为 0.198，20w 为 0.134。序列全程变化更大：相对质心轨迹的峰峰值分别约 0.819、1.445、1.014 像素。三个 q 窗×三个能量窗得到的漂移轨迹相关性均 >0.9995，最大 RMS 差 <0.013 像素。

q 校正采用像素单元与目标区间的重叠权重，保存每帧的计数积分及分箱相关性来源。合成平坦/线性信号检验通过。以下“时间强度差”是后 50 帧相对前 250 帧的 0.3–1.8 eV 积分，均除以同期弹性参考；预测指标是留出帧的平均标准化残差平方，约 1 是诊断参考线，不是精确显著性检验。

| 数据、q / Å⁻¹ | 仅能量对齐：时间强度差 | 加 q 校正后 | 留出预测指标：校正前 → 后 |
|---|---:|---:|---:|
| 590，−0.005 | −8.81% | −0.45% | 2.43 → 1.07 |
| 590，+0.005 | +10.37% | +1.33% | 2.03 → 1.11 |
| n0，−0.005 | −3.70% | +0.35% | 1.17 → 0.97 |
| n0，+0.005 | +5.12% | +0.99% | 1.31 → 1.08 |
| 20w，−0.005 | −1.04% | +0.64% | 1.10 → 1.06 |
| 20w，+0.005 | +2.60% | +1.22% | 1.05 → 1.06 |

**主张：相对动量漂移是 590、n0 低 q 强度时间变化的重要来源。** 依据是独立弹性信号测出的位移、正负 q 变化方向、参考窗稳定性，以及校正后改善的非弹性谱预测。这是一项看到异常后追加的受控分析，下一次独立采集应预设它作为验收项目。

校正对 ±0.005 Å⁻¹ 的低能 E₀ 改变量全部小于 4 meV，主要改善时间强度一致性。在 +0.015 Å⁻¹，预测没有普遍改善：590 1.53→1.61，n0 1.30→1.32，20w 0.951→0.947。高 q 的不稳定需要进一步处理计数与模型可识别性。

## 3. 哪些谱参数目前值得使用

以下为**原预设协议、双分量 DL、有限接收、逐帧能量对齐**的结果，未将后追加的 q 校正与原 bootstrap 误差混用。两分量是低能谱带的描述分量，与历史论文的全能区 B1/B2 命名不同。

| 数据，q=+0.005 Å⁻¹ | 低能 E₀ / meV | 低能损失 apex / meV | 高能 E₀ / meV | 高能损失 apex / meV |
|---|---:|---:|---:|---:|
| 590 | 726.7 | 644.8 | 1547.1 | 1340.5 |
| n0 | 713.3 | 657.6 | 1535.8 | 1350.8 |
| 20w | 745.7 | 682.3 | 1601.3 | 1418.8 |

低能分量 Γ 在这三个位置约 565–693 meV，高能分量约 1514–1608 meV，均为很宽的模型分量。E₀、裸损失峰顶、原始计数峰顶和 Γ/FWHM 必须区分。

时间留出中，双分量在 30 个分箱位置中的 19 个给出更小残差；±0.005 的六个位置均改善，但改善量随数据不同。合成单峰加噪后，16 次双分量拟合中有 6 次给出无边界的双峰解；所以收敛与较小残差不能单独识别两个 plasmon。这个小样本只说明伪拆峰可能发生，不能把 6/16 当成校准过的假阳性率。

原始图与残差保存在 `summary/representative_fits.png`。本轮支持“该低能谱带可以用两个宽分量更好地描述”，物理模归属仍须独立材料和响应证据。

## 4. 统计误差与模型敏感性

每个选定位置各做 128 次 IID 与 128 次长度 10 的块重采样。2304 次中：**2083 次无边界收敛，139 次未收敛，79 次边界，3 次零幅度**。所有结果保留。下面区间是长度 10 重采样中无标志拟合的 2.5–97.5 百分位，是条件区间。

| 数据 | q / Å⁻¹ | E₀ 95% 条件区间 / meV | 无标志比例 |
|---|---:|---:|---:|
| 590 | +0.005 | 702.8–752.7 | 97.7% |
| n0 | +0.005 | 693.3–728.2 | 93.8% |
| 20w | +0.005 | 728.5–771.7 | 100% |
| 590 | +0.015 | 645.2–975.2 | 98.4% |
| n0 | +0.015 | 693.1–1075.4 | 96.1% |
| 20w | +0.015 | 603.7–1044.2 | 71.9% |

在 −0.005，590/n0 无标志比例分别只有 71.1%/82.0%；这两处的条件区间不能被当成完整不确定度。汇总表同时保留所有成功拟合（含边界）的百分位，以便检查筛选影响。单初值热启动导致的数值失败也不能直接解释成物理不可识别。前 64 与 128 次的区间宽度仍可相差约 25%，当前是探索级误差估计，未验证精确覆盖率。

**模型选择带来的变化更大：**

- n0 在 +0.005，不做能量对齐使低能 E₀ 增加 61.9 meV，而 apex 仅增加 2.1 meV。这说明振子参数与峰顶对处理误差的响应不同。
- 同一点改用对称 Lorentzian，三组低能 apex 分别改变约 +79、+75、+55 meV。
- 拟合上限从 1800 扩到 2100 meV，高能 E₀ 分别增加约 343、339、499 meV，20w 还撞到新上限。**高能分量 E₀ 暂不适合被当成精确的本征模式色散点。**
- 在最小标称 q=+0.0025，几何/运动学替代模型能使低能 apex 改变数十 meV。接收函数尚未独立标定，不能据此外推 q→0 的能隙。

20w 在 +0.005 的低能 apex 比 590 高约 37.6 meV；但采集几何、未知结构、封装与同层重复差异都混在一起。本轮不把文件名层数转成因果厚度效应。

## 5. 最小模型已完成什么

Python 实现了准静态二维散射因子、有限 q 接收积分、能量卷积、DL 响应、带非局域屏蔽的长波 Drude/RPA 色散，以及条件性的双导电层耦合极点。均有明确单位与输入参数。

- 固定材料振子 E₀=700 meV、Γ=500 meV，裸损失 apex=655.5 meV；仅因运动学因子变化，标称 q 从 0.0005 增至 0.03 Å⁻¹时，窄接收的计数峰顶可以从 156 移到 656 meV。孔径平均又改变这条峰脊。该结果是机制反例。
- 屏蔽模型满足低 q 的 √q 极限及高 q 的饱和极限；另一个演示对具有色散的响应整体做 Q 积分，明确指出只平均散射因子还不够。
- 40 个独立 Python 合成样本，各做单/双分量拟合；无噪声、正确模型下 E₀ 最大恢复误差 <0.001 meV。低计数噪声样本的稳定性明显下降。
- 检查了能量加权谱和规则、幅度线性、能量卷积面积、孔径积分收敛、动量和能量单位。实测采用的 MATLAB 接收积分，相对加密节点在所查条件下最大差约 0.152%。

这些模型的 A、屏蔽长度和层间距都标为示意参数；没有为 Bi/BiSb 指定未经测定的晶相、n₂D、m* 或介电常数。原始文献 DOI、适用范围、模型推导和 DFT/RPA 扩展路线见 [METHODS.md](METHODS.md)。

## 6. 下一轮应落实的改进

1. **把双轴漂移与输入校验做成通用数据层，并在 GUI 中提供可见质控。** 导入原始帧时展示元数据零点/实测零点、能量漂移、q 质心、坏通道和处理前后线宽；保持原始帧可回溯。下一次验收用已知漂移合成数据和这三组真实数据，检查积分守恒与前后时间段预测。
2. **把每个拟合点的可信度放到手动分析界面。** 同时显示 E₀/apex、边界状态、bootstrap 有效率、残差和窗口敏感性；高 q 的数百 meV 区间应直接提示“参数未约束”。允许人工选择模型与排除点，并保存原因。先补数字诊断，再考虑全 q 色散模型。
3. **采同一区域、两种接收条件的数据，用完整测量算子共同拟合。** 独立记录狭缝透过率、二维探针角分布、q 零点/标定和封装厚度。用一组接收条件拟合、预测另一组，以检验 \(\langle K(Q,E)L(Q,E)\rangle\)。现有 10w/20w 还混有样品区域和层数标签，不能承担这项控制实验。
4. **材料理论由结构证据驱动升级。** 先确认 Bi-rich BiSb 的晶相、层数、成分、晶向及 MoS₂ 厚度；随后用分层介电/能带 RPA 分离自由载流子、带间连续谱与层间耦合。强 SOC 和二维 Coulomb 截断需进入材料级计算。当前 CPU 模型已可检验处理和几何机制，不必等待大规模 DFT。

每组 300×10 s 序列约覆盖 50 分钟曝光，应保留逐帧数据并检查随时间的束心变化。可以把长采集组织成有参考检查的短段，再合并分析。测量低温/不同载流子密度或 MoS₂-only 区域将提供区分阻尼、背景和集体响应的独立证据；具体条件应依据已确认结构和实际分辨率决定。
