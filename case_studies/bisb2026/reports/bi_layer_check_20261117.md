# 2026-11 的 Bi 数据层数是否一致（2026-11-17）

结论先说：**在 BiSb 能区分一层和两层的指标上，可用的四组 Bi 数据（三个区域）彼此一致，层数应当相同。** 最干净的指标是高能成分 E₀ 外推到 q = 0 的值：BiSb 两层比一层低 130–150 meV，四组 Bi 之间（包括换几何）最多只差约 90 meV。另外，四组 Bi 的高能 E₀ 斜率都是正的，没有一组像 BiSb 一层那样为负。Bi1107_20w 的双成分拟合不受约束，这组判断不了。

## 做法

- 7 组数据都用同一套 `b1_low_branch_matlab`（联合 ZLP、二维运动学因子、两个 Drude–Lorentz B1 成分），取原生单通道 0.0005 ≤ |q| ≤ 0.005 Å⁻¹，两种模型都收敛、低能成分没被标记（贴边、截断、合并或过弱）的分箱。
- 每个量在 +q、−q 两侧分别拟合直线 y = a + b|q|，报两侧平均。误差包含拟合标准误和 ±q 差的一半。另用 0.001–0.004 Å⁻¹ 重做一遍，检查范围的影响。
- BiSb 三组直接读 10-24 的结果（`paper_results/b1_low_branch_matlab_20261024/`），Bi1117_20w 读 h = 0.0033 那一轮（`b1_low_branch_bi1117_20261117/h0p0033/`）。其余四组本轮新跑，配置为 `b1_low_branch_bi_config`：留出最后 1/6 的帧，单通道区上限取整到 dq 的整数倍。
- h 都按"10w 0.0066、20w 0.0033"借用。Bi1107 两组的 h 本轮才写进登记表，同样是借用值。Bi1117_20w_2meV 的 dq 用 0.000128（按色散比 2.049/4 缩放）。

1. **BiSb 里能分开一层和两层的指标，是高能成分 E₀ 的截距和斜率。** 两组一层（590、n0）的截距约 1640 meV、斜率为负；两层截距低 130–150 meV、斜率为正。计数峰顶的斜率（低能 25–35、高能 210–260、单成分 160–220）三组完全重叠，不能区分层数。低能 E₀ 的截距只差约 24 meV，斜率只差约 13（约 3σ），都偏弱。
2. **几何本身翻不了高能斜率的符号。** BiSb 的一层都是 10w、两层是 20w，层数和几何同时变。Bi1117 同一区域（相距 0.9 μm）的 10w 和 20w：高能斜率 +38 和 +27（窄范围 +28 和 +26），截距 1336 和 1414 meV。换几何最多让截距变约 80 meV、斜率变约 11，比 BiSb 一层和两层之间的差都小。
3. **四组可用的 Bi 互相一致。** 高能 E₀ 截距在 1336–1414 meV（窄范围 1371–1463），斜率都为正。低能 E₀ 在约 600 meV 附近基本不随 q 变。这四组覆盖三个区域：11-07 的 10w 区、11-17 的主区（10w + 20w）、11-17 的 2 meV 区（距主区 22 μm）。
   - 区域之间最大的分歧在窄范围的高能斜率：Bi1107_10w 是 +3 ± 7，2 meV 那组是 +46 ± 3。窄范围点少，Bi1107_10w 在 0.0025–0.003 处有一个下凹。宽范围里它是 +26 ± 11，和其他组一致。
   - Bi1107_10w 的低能 E₀ 截距比 11-17 各组高约 40–60 meV。差别只出现在 |q| < 0.0015，从 0.002 起和其他组重合。
4. **Bi1107_20w 判断不了。** 38 个分箱里有 31 个的高能 E₀ 顶在拟合上界 1800 meV，低能成分在 0.003 以后乱跳；两个成分比一个成分的留出改善中位数为 0。这组本来就是信号最弱、q = 0 没有谷的那组。它和其他组不一致，原因是数据撑不起双成分模型，不能读成层数不同。
5. **BiSb 的一层/两层差别大于 Bi 的区域散布。** Bi 三个区域之间高能截距最多差约 90 meV（其中包含换几何），而 BiSb 两层和一层差 130–150 meV。所以 BiSb 的差别不太可能只是"两块不同区域"。不过 590 和 n0 的照明区部分重叠，BiSb 一层本身还没有真正独立区域之间的重复。

## 不能下结论的部分

- **Bi 的绝对层数读不出来。** Bi 的高能截距（约 1340–1460 meV）比 BiSb 一层和两层都低，材料不同，BiSb 的数值不能直接拿来对照。Bi 的斜率是正的，和 BiSb 两层同号。如果这些 Bi 区域确实是单层，那就说明"斜率符号对应层数"不能从 BiSb 直接搬到纯 Bi 上。要回答"Bi 是几层"，需要一块已知是两层的 Bi 作参照。
- h 都是借用的，没有实测。此前的 h 扫描表明，高能成分在小 q 处对 h 敏感；这里所有数据都用了同一套 h 约定，这一点算进了比较的口径里。
- 误差只包含拟合和 ±q 差，没有算入背景模型和竞争解。
