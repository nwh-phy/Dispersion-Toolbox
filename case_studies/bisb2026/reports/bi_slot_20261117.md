# 2026-11-17 纯 Bi 宽动量 slot 扫描

## slot-v4：探测器几何校正（当前结果）

结果：`paper_results/bi_slot_20261117/20261117_164710/`，图 11–17 与 `v4_summary.txt`。入口不变，`bisb_slot_analyze(bisb_slot_config())`；几何校正在 `bisb_slot_geometry`，坐标变换在 `bisb_slot_regrid`（`tests/test_bisb_slot_regrid.m`，4/4 通过）。同目录 01–10 仍是 v3 几何的产物。

v3 的对齐是对的，但沿 slot 的探测器几何有三处没修，它们共同制造了 v2/v3 报告里最显眼的两个数：右侧强斑“575 meV”和中央两侧“24 meV 峰移”。两者都是仪器效应，不是物理。

1. **弹性零点随通道变化。** 弹性线沿 slot 在 −25.5 至 +40 meV 之间（通道 84–385）：两斑之间左侧约 −20 meV、右侧约 +17 meV，靠近 slot 两端上翘（图 11）。逐通道在 ±60 meV 内取弹性峰，298/324 个通道直接测到；穿过直通束的斜条纹（E ≈ 2.23 meV/通道 × k + 3 meV，增益侧拟合）所在的通道先遮掉再插值，5 通道中值平滑。
2. **损失信号的 q 位置随能量移动。** 直通束和 ±G 三个锚点在 0.3–1.7 eV 六个能区的 q 峰顶满足 c = c₀ + k + (0.556 − 0.00429 k)·E[eV]：每 eV 平移 0.56 通道，同时放大率减小 0.43%，不动点在通道 364（直通束右侧 129 通道），18 个点的残差 rms 0.08 通道（图 12）。左斑在 1.15 eV 处移动 1.3 通道，右斑几乎不动，单一平移解释不了，所以按放大率变化建模。
3. **分箱以直通束为中心对称。** c₀ = 234.594，7 通道奇数宽 bin，k = −150…150。v3 的“中央左/右”两个区间中心分别在直通束左侧 6.1、右侧 1.9 通道，本身就不对称。

**验收：Bragg 斑处的谱对得上中央谱。** 两个 Bi 斑处扣掉 ±10 通道邻近背景后，谱就是中央谱的双散射复本：复本强度与弹性强度之比为 0.978、0.984。整谱能量位移拟合（350–2200 meV）：

| 斑（通道） | v3 位移 / meV | v4 位移 / meV |
|---|---:|---:|
| −G（99.77） | −15.6 | +2.9 |
| +G（371.31） | +33.1 | −8.6 |

+G 的上升沿在 v4 已经对齐，剩下的 −8.6 meV 主要来自 1.8 eV 以上的谱形差；斑处能量零点的系统误差按 ±9 meV 计。外侧斑（72.87 通道，MoS₂ 候选）在 slot 边缘：它的弹性零点是 +38 meV，按此校正后复本反而偏 −17 meV，说明这个斑被 slot 边缘截切，弹性零点不代表复本的零点，所以分析范围从通道 84 开始，把它排除在外。

**±q 检验。** 直通束轮廓本身就偏斜：弹性强度 I(+k)/I(−k) 在 k = 3、5、7 通道为 1.24、1.65、1.76。与能量无关的强度比不改变谱形，也就不移动峰位，因此检验量取 ln(I(+q)/I(−q)) 在 350–1600 meV 内对能量的斜率。v4 的 21 对全部在 ±10%/eV 以内，中位 3.6%/eV；v3 几何下 15/21，|q| = 0.098 Å⁻¹ 处为 62%/eV（图 15）。这一对在 v4 的两侧低能峰顶为 534.4 与 534.9 meV。由斜率在对称化谱上推出的峰顶系统误差中位 1.8 meV，最大 14 meV（+G 斑所在 bin）。

**物理读数（对称化，未扣背景峰顶，0.4–0.8 eV 搜索）。** Γ（|q| ≤ 0.05 Å⁻¹）537 meV；|q| = 0.10、0.20 Å⁻¹ 为 533、530 meV，这一范围内峰基本不色散。|q| ≳ 0.3 Å⁻¹ 后单个 bin 的峰顶在 445–750 meV 之间跳动，峰已不明显，不读色散。对称化峰顶目前只有点估计，空间行 bootstrap 只做在 ±q 检验上。

**动量标定。** Å⁻¹ 横轴用 ARM200 暂定值 dq = 0.014024 Å⁻¹/通道（`bi_slot_arm_calibration_20261117.md`）。若外侧斑是 MoS₂(100)（a = 3.160 Å），得 dq = 0.014196，高 1.23%，对应 ±G 这对 Bi 斑的晶面间距 3.26 Å（暂定值按 3.30 Å 取）。标定热图：`13_v4_dispersion`（0.2–1.5 eV）、`13_v4_dispersion_wide`（0.2–3 eV）、`14_v4_sg21/sg41`（仅能量方向 Savitzky–Golay，显示用）、`16_v4_symmetrized`。`20261117_143436/arm_calibration_*` 下的旧标定热图建在无效的 v2 对齐上，由这些图取代。

**仍未解决。** 斜条纹的来源未知，它在 +q 一侧落在 0–340 meV 损失区，150–350 meV 的低能分析只能用 −q 一侧；需要同条件的真空参考来判断它和弹性零点曲线是否属于仪器本身。

> **slot-v3 更正（2026-11-17）**：下文保留 slot-v2 试跑记录。v2 对每个空间点、每个动量通道独立寻找 ZLP，会在弱弹性通道锁定非弹性噪声；其 −64 至 +120 meV 位移、31.58 meV 中位宽度和峰位表不再作为结果引用。v3 改为每个空间点仅用直通束五个通道测一个位移并应用到全部动量通道，361/361 参考有效，位移为 −8 至 +8 meV。v3 结果在 `20261117_143929/`，已被上面的 v4 取代。下文其余内容仅作 v2 历史证据。

本次最明确的观测是：约 0.5–0.6 eV 的宽损失峰在中央强斑和两侧衍射强斑附近重复出现；中央强斑两侧有可重复的局部峰移。现有数据尚未给出贯穿整个 slot 的稳定色散支。

## 数值结论

弹性强度的主要局部极大位于探测器通道 **73、100、235、371**。100 和 371 相对 235 分别相差 −135、+136 通道，几何上与中央束两侧一对衍射斑相容；需用原始衍射/slot 图确认。不能仅凭这组间距指定晶向或 Å⁻¹ 标度。

下表为**未扣背景的实测峰顶**，经逐位置、逐通道零损失对齐；区间是 19 个空间扫描行、200 次 block bootstrap 的 95% 区间。它描述扫描采样变动，不含背景模型、动量接受范围和独立重新采集的系统误差。检测失败的重采样不进入条件分位数，故同时给出成功率。

| 位置（通道） | 峰顶 / eV | 95% 区间 / eV | 重采样成功率 |
|---|---:|---:|---:|
| 左侧强斑 89–104 | 0.502 | 0.485–0.557 | 98.5% |
| 中央左侧 225–232 | 0.507 | 0.500–0.512 | 100% |
| 中央右侧 233–240 | 0.531 | 0.526–0.536 | 100% |
| 右侧强斑 369–376 | 0.565 | 0.500–0.599 | 93.5% |

中央右侧减左侧为 **24.3 meV**；配对扫描行 bootstrap 区间 **18.3–32.3 meV**。这是实测峰顶的局部变化；换算色散斜率还需要动量标定，解释本征模式还需要接受范围与背景约束。右侧强斑峰位对平滑窗较敏感（11/21/31 通道平滑给出约 0.535–0.551 eV），不宜把 0.565 eV 当成高精度模态能量。

中央右侧及两侧强斑在约 1.1–1.3 eV 还有宽肩部，中央左侧的高能尾明显更弱。当前只保留谱形差异，不据此拆分两条本征分支。两强斑之间：左侧宽区间 121–200 合并后仍可见约 0.51 eV 的弱宽峰，右侧 265–344 没有稳定的单一峰顶；逐 8 通道结果多数受噪声和背景选择影响。现有图不支持将散点连成一条跨全窗色散。

## 背景与空间检验

最初尝试的 220–380 meV 范围部分落在峰上升沿，在强斑附近得到负的幂律指数，因而拒绝作为物理尾巴。诊断运行保留在 `20261117_143303/`，不是最终峰位依据。

最终检查三个更低能窗口：160–220、180–240、200–260 meV。中央左侧扣尾后的峰顶为 **0.552–0.563 eV**；中央右侧为 **0.613–0.686 eV**。背景系统差异明显大于几 meV 的统计误差，因此以未扣背景的峰顶与谱形作为主交付，未声称得到了唯一的本征峰能量。幂律指数非正的拟合不用于峰位；全负残差返回无可提取峰。

中央通道 225–240 的 361 个空间位置中，345 个可提取宽峰；有效点峰位的 5/50/95 分位为 **0.494/0.529/0.583 eV**。I(0.4–0.8 eV)/I(1.2–1.6 eV) 的对应分位为 **1.303/1.335/1.405**；首行均值 1.331、末行 1.413，增加 **6.22%**。这有扫描行趋势；单次扫描同时改变位置和时间，暂不能区分样品空间变化、束照演变与仪器漂移。

## 方法、复用与验证

1. 使用 Fred Sigworth 的 BSD MATLAB `ReadDMFile`，增加可选 ImageList 索引、第四维与标定字段输出；该 DM4 只有一个 image member，不能用上游默认 member 2。
2. 在实测照明 slot 内取通道 65–388；保存全 512 通道原始求和图。复用 `qe_zlp_integer_align`，每个扫描点每个通道只用弹性峰定整数能量平移，不移动动量轴、不镜像合并 ±q、不做运动学因子相除。116,964/116,964 个局部参考通过既有有效性判据；共同能量支持范围内无循环回绕，并核验一次逐元素映射与原始切片完全相等。
3. 局部校正位移范围 −64 至 +120 meV；校正后的通道 ZLP FWHM 中位数 **31.58 meV**，5–95% 分位 **28.14–38.84 meV**。这包含探测器通道差异，不把它当成单一仪器分辨率。
4. 8 通道分箱；复用 `qe_zlp_center`、`qe_powerlaw_tail`、`qe_peak_apex`、`qe_plot_heatmap`。峰顶提取使用 15 通道（60 meV）移动均值定位，再在原始谱 ±60 meV 拟合抛物线。热图按每列 400–1500 或 400–3000 meV 面积归一化，仅作谱形显示，亮度不代表绝对散射强度。
5. 同时保留“先求和再对齐”对照。主分析不使用未知 q 轴下的 P2b 接受算子或旧 10w/20w 标定。
6. macOS MATLAB R2026a 实际运行完成；定向测试 **13/13 通过，无跳过**：谱辅助函数 6、DM4 小型三/四维夹具 2、登记表 5。未运行全量测试或 GUI 测试。首次测试的 2 个 DM4 夹具因上游短数组返回 double 而非 single 的类型预期失败，修正数值比较后全部通过；实际大数组读取为 single。

入口：`bisb_slot_analyze(bisb_slot_config())`；`bisb_slot_summary(out)` 可从已保存结果重做强斑与空间对照。原始 ZIP、DM4 和计算产物不入 Git。源代码在 main 本地提交，原有未提交改动不纳入。
