# 2026-11-17 Bi 20w 高动量分辨序列（Bi1117_20w）首轮分析

结论先说：这组数据在 q = 0 给出清楚的独立损失峰，**原始峰顶 446 ± 2 meV**，扣 150–250 meV 幂律尾后 **479 ± 2 meV**（200–300 meV 窗口为 489 meV），前面 318 meV 处有谷。峰随 |q| 连续上移：0.002 Å⁻¹ 处 579 ± 4 meV，|q| ≈ 0.003 处斜率最大，|q| ≥ 0.005 后峰脊平在 **1.27–1.43 eV**。11-07 那组 20w 的 q = 0 谱没有谷、单调下降，这组同样几何的数据把谷测出来了；差别来自那组的样品信号相对 ZLP 尾巴弱一半，不是 20w 几何本身的性质。

±后面是 6 个时间块（每块 60 帧）之间峰位的标准误，只含计数噪声和一小时内的漂移，不含区域差异、背景模型和动量标定的系统误差。dq 暂借 1-20 的 20w 标定（0.00025 Å⁻¹/通道），这台相机没有单独标定；下文所有 |q| 和斜率都随 dq 等比例变化。

## 结果

### q = 0 单谱

| | 11-17 20w | 11-07 20w | 11-07 10w（参照） |
|---|---:|---:|---:|
| 原始峰顶 − ZLP / meV | **446 ± 2** | 无内部极大 | 486 |
| 扣 150–250 meV 尾 / meV | **479 ± 2** | 521 ± 11 | 511 |
| 扣 200–300 meV 尾 / meV | 489 | 542 | 524 |
| 谷深 I_peak/I_min − 1（谷位置） | 0.20（318 meV） | 无谷 | 0.47（323 meV） |
| I(450 meV)/ZLP 峰高 | 2.55×10⁻⁵ | 1.32×10⁻⁵ | 4.27×10⁻⁵ |
| I(250 meV)/ZLP 峰高 | 2.56×10⁻⁵ | 2.98×10⁻⁵ | 3.60×10⁻⁵ |
| 约 130 meV 积碳声子超出局部幂律 | **0.004** | 0.16 | 0.33 |
| ZLP 半高宽 / meV | 34.6 | 26.6 | 29.8 |
| q = 0 通道 300–1500 meV 计数 | 7.35×10⁵ | 1.80×10⁵ | — |

1. **谷的有无由峰与尾巴的强度比决定。** 两组 20w 在 250 meV 处的尾巴相对 ZLP 差不多（2.56 vs 2.98×10⁻⁵），450 meV 处的样品信号新数据高 1.9 倍。I(450)/I(250) 新数据 1.00，11-07 20w 只有 0.44，峰被尾巴盖住，所以没有谷。11-07 20w 的"q = 0 从 ZLP 尾巴一路连续下降"不能再当作 20w 下连续谱的证据；连续谱是否存在，要靠扣尾之后 250–350 meV 的残余强度来判断（扣 150–250 meV 尾后，250 meV 以上残余的最小值是峰高的 13%，这个数受尾巴模型控制，本轮不据此下结论）。
2. **新区域的 q = 0 峰比 11-07 低约 40 meV。** 同为 20w、同样扣 150–250 meV 尾：479 ± 2 对 521 ± 11 meV，差 42 ± 11 meV；|q| ≤ 0.002 的每个点（同样扣尾）新数据都低 40–120 meV。这是两个不同区域之间的差别，区域间重复性还没有数据，暂不归因于层数或衬底。
3. **新数据几乎没有积碳。** 130 meV 声子超出量 0.004（6 块在 −0.003 至 0.023 之间，不随时间增长），11-07 两组是 0.16 和 0.33。背景窗口 150–250 meV 因此比 11-07 更干净。
4. **ZLP 变宽了。** 每个时间块的 ZLP 半高宽都在 33.7–35.3 meV，是这次上机的仪器状态，不是逐帧对齐（整数通道平移，帧间位移 −24 至 +12 meV）造成的。能量分辨比 11-07 20w 差 8 meV。

- 0.001–0.002 Å⁻¹ 之间斜率 87 ± 4 meV / 0.001 Å⁻¹（按暂借 dq）。
- 0.0025 到 0.003 之间峰顶跳了 330 meV：那里的谱是 600–1200 meV 的平台（|q| = 0.003 时 I(500) : I(1000) : I(1300) = 0.84 : 1.00 : 0.91），44 meV 平滑后找不到第二个显著极大。逐原生通道的峰脊在 |q| ≈ 0.0027–0.003 有 720、820–870 meV 的中间点，所以读作**一条连续支**：q = 0 的 446 meV 起，在 0.003 附近最陡，到 |q| ≥ 0.006 后平在 1.3–1.4 eV。
- 单靠峰顶区分不了"一支迅速变宽"与"低能支衰减、高能支接上"两种情况。BiSb 的 B1 曾用双分量模型拆出两支，这组数据的 |q| = 0.0025–0.004 是同样问题的检验区间，计数也够（见下一步）。
- |q| ≥ 0.006 后各点块间误差 20–90 meV，个别 |q| 没有内部极大（NaN），高 q 端单个原生通道的计数不够定峰。

### 运动学因子（沿用 2026-11-16 的做法）

逐通道除以二维运动学因子（h = 0，σ_probe = 0.000232 Å⁻¹）后，|q| ≤ 0.001 的最大值都被推到窗口上沿 1796 meV（q = 0 时 K(1700)/K(250) = 1/746），与 11-07 10w 的结果相同，不提供峰位信息。|q| ≥ 0.002 时除后峰脊在 1.30–1.38 eV，|q| ≥ 0.008 时 1.42–1.50 eV。h = 0.0066 的虚线是 10w 狭缝的几何值，20w 的几何值约为一半，只作 h 敏感性的示意。

背景检验里"镜像增益侧"一项这组数据不能用：ZLP 落在原始能量轴的 −48 至 −84 meV，轴从 −400 meV 开始，增益侧只有约 300 meV，外推用的"最外 100 meV 平均"仍在 ZLP 尾巴上，扣掉的量偏大（占信号 24%，11-07 只有 1–2%）。

### 一小时内的变化

峰位稳定（q = 0 六块之间标准误 2 meV），但损失信号相对 ZLP 下降：I(450)/I₀ 从 2.85 降到 2.36×10⁻⁵（−17%），I(1000)/I₀ 同样 −17%，而 250 meV 处只降 6%。所以谷深从 0.25 降到 0.17。积碳声子不增长，弹性线的 q 宽度不变（0.00024–0.00026 Å⁻¹），下降的是样品本身的损失强度：照射区的样品在变（损伤或空间漂移），具体是哪一种这组数据分不出。
