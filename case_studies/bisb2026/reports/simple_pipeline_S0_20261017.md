日期：2026-10-17。计划见主工作区 `docs/plans/simple_pipeline_20261017/PLAN.md`。
- 结果（主工作区，不进 git）：`paper_results/b1_adaptq/20261009T054142Z/simple/s0_f9eca8a3/`，用时 16 s。
- 脚本（分支 `simple-pipeline-20261017`）：`case_studies/bisb2026/scripts/b1_simple_s0.m`、`b1_simple_config.m`、`b1_simple_root.m`。算子、P2b 配置和数据都读主工作区里未提交的文件，见 `b1_simple_root.m`。

## 一句话结论

**按计划的判据（偏差小于 P2b 的统计误差），0.0015–0.005 内没有一个 q 通过，q_min 定不出来。** 原因有两个，性质不同：

1. **精度**：逐通道独立拟合本身就比 P2b 粗得多。同样的计数下，期望误差是：
   - 低能支 E0：57–84 meV（P2b 8–18）；
   - 低能支峰顶：25–41 meV（P2b 4–13）；
   - 高能支峰顶：34–54 meV（P2b 6–10）。

   B1 两支都强阻尼，单条谱上只有一个宽包络，分不清 E0、Γ 和振幅。P2b 的精度来自 20 个通道 × 6 个时间块共享一个 L(Q,E)，不是来自测量模型。
2. **准确度**：简化模型漏掉的测量效应造成确定性偏差。无噪声拟合的 χ²/点只有 0.004–0.02，谱形完全拟得上（`fig_s0_spectra.png`），偏差全部是参数简并下的错位。

计划里的判据是我写错了：我默认逐通道拟合的误差和 P2b 相当，实际大 3–6 倍。

## 1. 做了什么

- 真值：P2b 主版本的模型计数 `mainMu`（块算子、宽成分、共享 L、拟合出的尾巴），每个通道把 6 个时间块加起来，不加噪声。
- 简化模型（计划的定义）：单通道二维运动学因子，探针按高斯 σ = 3.4×10⁻⁴ Å⁻¹（P2a 窄成分），不含宽成分；两支 DL，每个通道自己拟合；热因子；高斯分辨 FWHM 23.2 meV；窗口、尾巴、方差、起点都同 P2b。
- 偏差 = 简化拟合值 − P2b 曲线在名义 |q| 处的值。期望误差 = 以真值计数作泊松方差的 Jacobian 误差。
- 诊断版本，每个只改一项：y 方向几何同 P2a（h = 0.0005，σ_y = 4.5×10⁻⁴）；留数在通道内 ∝ Q；不加探针展宽。

## 2. 偏差（主版本，单位 meV；格式为 +q / −q）

| \|q\| | 低能支 E0 | 低能支峰顶 | 高能支峰顶 | 高能支 E0（只报告） |
|---|---|---|---|---|
| 0.0015 | +15 / +10 | +31 / +4 | −7 / +35 | −36 / +4 |
| 0.002 | +19 / +47 | −7 / −15 | +174 / +176 | +55 / +8 |
| 0.0025 | +51 / +102 | −15 / −14 | +109 / +105 | +33 / −4 |
| 0.003 | +38 / +94 | −19 / −20 | +59 / +61 | +21 / −11 |
| 0.0035 | +30 / +76 | −17 / −23 | +28 / +31 | +8 / −18 |
| 0.004 | +22 / +61 | −18 / −25 | +16 / +19 | +5 / −17 |
| 0.0045 | +17 / +51 | −17 / −25 | +10 / +12 | +4 / −15 |
| 0.005 | +16 / +44 | −17 / −25 | +10 / +8 | +11 / −9 |

- 低能支 E0 一律偏高，在 0.0025–0.003 最大，到 0.005 仍有 +15–45。
- 低能支峰顶一律偏低约 20 meV，从 0.002 到 0.005 基本不衰减。
- 高能支峰顶在 0.002–0.003 大幅偏高，0.0035 起降到 30 以内。
- −q 侧的偏差普遍更大。P2a 的宽成分偏向 −q，二者一致。
- 三个诊断版本的偏差和主版本几乎一样（`fig_s0_bias.png` 中的细线）。所以偏差不来自 y 方向几何、通道内的 Q 权重或探针展宽。剩下 S0 里没法单独关掉的是 6.4% 的宽成分，以及切片能量核和块间漂移。

## 3. 物理上的后果

直接用简化流程处理 590，会在 q ≤ 0.003 造出假的负色散：
- 低能支 E0 从 0.0025 处约 780–830 meV 降到 0.005 处约 700–730 meV。P2b 真值是 728 → 685，基本平。
- 高能支峰顶从 0.002 处 1.52 eV 降到 0.005 处 1.33 eV。P2b 真值是 1345 → 1324。

这又是一个"处理方式造出色散"的例子，和直接寻峰造出"小 q 趋零"同类。

## 4. 换一把尺子：用简化流程自身的误差

三项判定量的偏差都小于简化流程自身 1σ 的最低 q 是 0.0035（0.003 处 −q 侧低能支 E0 偏 +94，期望误差 84）。但这只说明偏差藏在误差里，代价是误差比 P2b 大 3–6 倍。而且低能支峰顶约 −20 meV 的偏差是同号的，多个通道合起来也平均不掉。

## 5. 对计划其余部分的含义

- **S3 的判据太松**：合成误差会在 60–90 meV，100 meV 的真实偏差也能通过，通过了也不说明什么。
- **旧的高 q 分箱结果（0.0055–0.0155）**：它们用的也是单通道模型。S0 在 0.005 处看到的偏差（低能支 E0 +15–45、低能支峰顶 −17 到 −25、高能支 E0 ±10）很可能延续到更高 q。P2b 报告里"高能支 E0 在 0.005 对 0.0055 有约 50–60 meV 的系统差"与此一致。色散拟合把 P2b 节点和这些分箱点放在一起，这一段的偏差会进入斜率和 ρ 下限。

## 6. 下一步（需要用户定）

- A. 停在这里，不做 S1–S3。|q| ≤ 0.005 以 P2b 为准；从 SI 只借展示（对齐后的 q–E 图）和误差棒（±q 不对称）的做法。
- B. 继续 S1–S3，q_min 取 0.0035，判据改为"偏差与简化流程自身误差之比"；结论最多是"粗略一致"。
- C. 把 S0 的真值延伸到 0.0055–0.0155（用 P2b 的算子算更高 q 的通道，L 在 0.005 以外取常数），量出旧高 q 分箱点的偏差。
